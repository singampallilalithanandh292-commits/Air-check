# Visakhapatnam Air Quality & Public Health Equity
**"Where you live shouldn't decide how long you live."**

## Project Overview
An end-to-end data analytics project analyzing air quality 
trends across Andhra Pradesh, with a focus on Visakhapatnam's 
industrial belt and its impact on public health.

## Tools Used
Python | pandas | SQL | SQLite | Tableau | Excel

## Key Findings
- Visakhapatnam avg PM2.5 (47 µg/m³) is 24% worse than Amaravati
- January is consistently the worst month (avg 79.7 µg/m³)
- Winter months regularly breach India's NAQI safe threshold of 60
